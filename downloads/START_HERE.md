# پنج لندینگ مستقل — راهنمای اجرا

هر پنج پروژه با Next.js، TypeScript و Tailwind پیاده‌سازی شده‌اند. تصاویر مفهومی اختصاصی و SVGهای تألیفی داخل پروژه‌ها قرار دارند. هیچ سرویس خارجی یا کلید API برای اجرا لازم نیست.

## اجرا

Node.js 24 پیشنهاد می‌شود. وارد پوشه پروژه دلخواه شوید و اجرا کنید:

```sh
npm ci
npm run dev
```

| پروژه | پورت |
|---|---|
| NOIR_ARCHITECTURE | 3001 |
| SYNAPSE_AI_SAAS | 3002 |
| VELOCITY_SUPERCAR | 3003 |
| MONO_FINTECH | 3004 |
| SONIQ_AUDIO | 3005 |

برای نسخه تولید: `npm run build` و سپس `npm start`. بررسی‌ها: `npm run lint`، `npm run typecheck` و `npm test`. برای تست مرورگری خارج از محیط ابری، یک بار `npx playwright install chromium` را اجرا کنید.

## پیش‌نمایش و گزارش

فایل PREVIEWS.html را برای دیدن اسکرین‌شات‌های دسکتاپ و موبایل باز کنید. تصاویر در پوشه previews هستند. نتیجه بررسی‌ها در VALIDATION.md و توضیح تصاویر و فونت‌ها در ASSET_CREDITS.md هر پروژه آمده است.

۲۸ تست مرورگری، build، lint و TypeScript عبور کرده‌اند. شش اندازه‌نمایش از ۳۶۰ تا ۱۹۲۰ پیکسل، تصاویر، منوها، تعامل‌ها، فرم‌ها و قواعد خودکار دسترس‌پذیری بررسی شدند.

## ماهیت دمو

این‌ها برندها و محصولات مفهومی‌اند. فرم‌ها اطلاعات را ارسال یا ذخیره نمی‌کنند. پاسخ‌های SYNAPSE از پیش نوشته شده‌اند؛ انتقال پول و احراز هویت واقعی وجود ندارد. گالری خودرو مجموعه تصاویر مفهومی است، نه مدل ۳۶۰ درجه. متریال‌های هدفون نمونه سطح هستند و تصویر اصلی را به‌صورت غیرواقعی رنگ نمی‌کنند.

کدها در مخازن محلی آماده‌اند؛ push به GitHub یا انتشار سایت انجام نشده است.
